## 為什麼 Embedding 不要放資料庫？

### ❌ 問題 1：效能災難

```python
# ❌ 錯誤做法：從資料庫讀取 embedding
def bad_vector_search(query):
    # 1. 生成查詢向量
    query_vector = openai.Embedding.create(input=query)['data'][0]['embedding']

    # 2. 從資料庫讀取所有 embeddings（災難開始）
    cursor.execute("SELECT id, embedding FROM documents")
    all_docs = cursor.fetchall()  # ⚠️ 可能上千筆，每筆 1536 維度！

    # 3. 在 Python 中計算相似度（超慢！）
    similarities = []
    for doc_id, embedding in all_docs:
        similarity = cosine_similarity(query_vector, embedding)
        similarities.append((doc_id, similarity))

    # 4. 排序取 Top 10
    results = sorted(similarities, key=lambda x: x[1], reverse=True)[:10]
    return results
```

**問題分析：**
- 🐌 **網路傳輸慢**：每個 embedding 1536 維度 × 4 bytes = 6KB，1000 筆 = 6MB
- 🐌 **記憶體爆炸**：所有向量載入記憶體
- 🐌 **計算慢**：Python 逐一計算 cosine similarity
- 🐌 **無法擴展**：資料量越大越慢（線性增長）

### ✅ 正確做法：使用專門的向量搜尋引擎

```python
# ✅ 正確做法：使用 Azure AI Search
def good_vector_search(query):
    # 1. 生成查詢向量
    query_vector = openai.Embedding.create(input=query)['data'][0]['embedding']

    # 2. 向量搜尋引擎內部優化（HNSW 演算法）
    results = search_client.search(
        vector_queries=[{
            "vector": query_vector,
            "k_nearest_neighbors": 10,
            "fields": "content_vector"
        }]
    )

    # 3. 只回傳 document IDs
    return list(results)
```

**優勢分析：**
- ⚡ **HNSW 演算法**：O(log N) 複雜度，不是 O(N)
- ⚡ **向量索引**：預先建立索引，毫秒級回應
- ⚡ **內建優化**：GPU 加速、近似搜尋
- ⚡ **可擴展**：百萬級資料也能快速搜尋

### 📊 效能對比

| 方案 | 1,000 筆 | 10,000 筆 | 100,000 筆 |
|------|----------|-----------|------------|
| PostgreSQL (暴力搜尋) | 2-5 秒 | 20-50 秒 | 3-5 分鐘 |
| PostgreSQL + pgvector | 500ms | 3-5 秒 | 30-60 秒 |
| **Azure AI Search (HNSW)** | **10-50ms** | **20-100ms** | **50-200ms** |

### 查詢流程詳解

#### 流程 1: 向量搜尋（語意理解）

```python

query = "我想學人工智慧相關的課程"

# Step 2: 生成查詢向量

    model="text-embedding-ada-002",
    input=query
)['data'][0]['embedding']

# Step 3: 向量搜尋（Azure AI Search）
vector_results = search_client.search(
    vector_queries=[{
        "vector": query_embedding,
        "k_nearest_neighbors": 20,  # 取 Top 20 候選
        "fields": "content_vector"
    }]

# Step 4: 取得 document IDs
doc_ids = [result['id'] for result in vector_results]

    query=query_sql,
    parameters=[{"name": "@ids", "value": doc_ids}]
```

### 3. 資料同步策略

```python
# ETL Pipeline: Cosmos DB ←→ Azure AI Search

class DataSyncService:
    def __init__(self):
        self.cosmos_client = CosmosClient(...)
        self.search_client = SearchClient(...)

    async def sync_document(self, doc_id: str):
        """同步單一文檔"""
        # 1. 從 Cosmos DB 讀取完整資料
        cosmos_doc = self.cosmos_client.read_item(doc_id)

        # 2. 生成 embedding（如果還沒有）
        if not cosmos_doc.get('_embedding_synced'):
            text = f"{cosmos_doc['title']} {cosmos_doc['content']['full_text']}"
            embedding = self.generate_embedding(text)

            # 3. 準備搜尋索引文檔（輕量級）
            search_doc = {
                "id": cosmos_doc['id'],
                "type": cosmos_doc['type'],
                "title": cosmos_doc['title'],
                "short_summary": cosmos_doc['summary']['short'],
                "department": cosmos_doc['metadata']['department'],
                "college": cosmos_doc['metadata']['college'],
                "year": cosmos_doc['metadata']['year'],
                "tags": cosmos_doc['metadata']['tags'],
                "content_vector": embedding  # ⭐ 只有這裡有 embedding
            }

            # 4. 上傳到 Azure AI Search
            self.search_client.upload_documents([search_doc])

            # 5. 標記已同步（避免重複生成）
            cosmos_doc['_embedding_synced'] = True
            cosmos_doc['_last_sync'] = datetime.utcnow().isoformat()
            self.cosmos_client.upsert_item(cosmos_doc)

    async def bulk_sync(self):
        """批次同步所有文檔"""
        # 查詢未同步的文檔
        query = "SELECT c.id FROM c WHERE NOT IS_DEFINED(c._embedding_synced)"
        unsync_docs = self.cosmos_client.query_items(query)

        # 批次處理
        for doc in unsync_docs:
            await self.sync_document(doc['id'])
```

```
1. 使用者上傳新 PDF → Blob Storage
2. ETL Pipeline 處理 → Cosmos DB
3. 自動生成 embedding → Azure AI Search

查詢流程：
1. 向量搜尋 → Azure AI Search（快速找到相關 IDs）
2. 批次查詢 → Cosmos DB（取得詳細資料）
3. 必要時 → Blob Storage（下載原始檔案）
```

## 實際使用範例

### 範例 1: 課程推薦

```python
@router.post("/api/recommend-courses")
async def recommend_courses(request: RecommendRequest):
    user_interests = request.interests  # ["人工智慧", "資料科學"]

    # Step 1: 向量搜尋找相關課程
    query_text = " ".join(user_interests)
    query_embedding = generate_embedding(query_text)

    vector_results = search_client.search(
        vector_queries=[{
            "vector": query_embedding,
            "k_nearest_neighbors": 30,
            "fields": "content_vector"
        }],
        filter="type eq 'course'"  # 只要課程
    )

    # Step 2: 取得課程 IDs
    course_ids = [r['id'] for r in vector_results]

    # Step 3: 從 Cosmos DB 批次查詢詳細資訊
    query = f"SELECT * FROM c WHERE c.id IN ({','.join(course_ids)})"
    courses = list(cosmos_container.query_items(query))

    # Step 4: 進一步篩選和排序
    filtered_courses = [
        c for c in courses
        if c['metadata']['credits'] >= 2  # 至少 2 學分
    ]

    # Step 5: 回傳結果
    return {
        "recommendations": filtered_courses[:10],
        "total_found": len(filtered_courses)
    }
```

```python
async def chat(request: ChatRequest):
```
